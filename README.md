# THINK LAB

考えを、見える形に。TT-senseiの思考ツールサイトです。

公開URL（GitHub Pages）：https://tt-sensei.github.io/THINK-LAB/

## 現在の機能

- 20種類の思考ツール
- 分類・キーワード検索
- ツールごとの使い方、活用場面、考えるヒント
- ナビキャラによる案内（6人からランダム）
- 直接入力、項目の追加・削除
- localStorageによる端末内の自動保存
- A4印刷・ブラウザのPDF保存
- スマートフォン、タブレット、PCに対応

## 技術方針

- 静的HTML / CSS / JavaScript
- API、サーバー、データベース、ビルド工程なし
- 入力データは利用中のブラウザ内に保存
- 外部ライブラリ、外部フォント、CDNは不使用
- ナビキャラ画像は共通素材リポジトリのWebPを参照

## ナビキャラ素材

画像は [TT-sensei/navi-character-](https://github.com/TT-sensei/navi-character-) の公開Web素材を参照します。素材のパス・ポーズは同リポジトリの `catalog.json` と `NAVI-USAGE.md` を基準にしています。画像に文字や吹き出しは埋め込まず、説明文はTHINK LAB側のHTMLで表示します。

## 入力内容について

入力内容はブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで再度開くと続きから利用できます。ブラウザのデータ消去や別端末への移行では引き継がれません。必要な内容は印刷またはPDFで保存してください。

## 印刷

ツール画面の「印刷・PDF保存」を押してください。印刷画面ではナビキャラや操作用ボタンなどを非表示にし、入力した内容をワークシートとして出力します。PDFにする場合は、ブラウザの印刷先で「PDFに保存」を選択します。
