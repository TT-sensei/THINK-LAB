# THINK LAB

**考えを、見える形に。**

THINK LABは、子どもたちが自分の考えを広げたり、比べたり、理由やつながりを整理したりするための思考ツール集です。授業の目的に合わせて道具を選び、画面上のシートに直接入力できます。

- **公開サイト：** https://tt-sensei.github.io/THINK-LAB/
- **リポジトリ：** https://github.com/TT-sensei/THINK-LAB
- **制作：** TT-sensei

---

## THINK LABでできること

- 30種類の思考ツールから、学習の目的に合うものを選べる
- 「広げる」「比べる」「分析する」「視点を変える」「順序立てる」「まとめる」の観点で探せる
- キーワード検索で使いたいツールを見つけられる
- ホーム画面のおすすめから、考えたいことに合うツールへすぐに進める
- 入力欄に直接書き込み、必要に応じて項目を追加・削除できる
- 図形ツールは図と入力欄が分かれていて、入力した文字が図の中に反映される（印刷では図だけを出力できる）
- ベン図の比べる対象や、マトリックス・座標軸の軸の名前を入力してシートに反映できる
- ふりがなの表示・非表示を切り替えられる
- ナビキャラの案内で、使い方や考えるヒントを確認できる
- 国語・社会・算数・理科など、教科での活用例を参考にできる
- 入力内容を端末内に自動保存できる
- A4印刷やブラウザのPDF保存に対応

## 使い方

1. [THINK LAB](https://tt-sensei.github.io/THINK-LAB/)を開きます。
2. 検索・カテゴリ・目的別のおすすめから、使いたいツールを選びます。
3. テーマや問いを入力し、考えを書き込みます。図形ツールでは右の入力欄に書くと、左の図の中に文字が反映されます。
4. 必要に応じて「項目を追加する」で入力欄を増やします。
5. 「印刷・PDF保存」から、ワークシートとして印刷またはPDF保存します。

入力内容は同じ端末・同じブラウザであれば、次回も続きから利用できます。大切な記録は印刷またはPDFで別に保存してください。

## 授業での活用

思考ツールは、使うこと自体が目的ではありません。学習課題や問いに対して、どのような思考を促したいかを考えて選びます。

- **考えを広げる：** 既有知識や経験、疑問、アイデアを出す
- **比べる：** 共通点・相違点・優先順位を明らかにする
- **分析する：** 原因と結果、根拠、部分と全体、概念どうしの関係を捉える
- **視点を変える：** 複数の立場や範囲から見直す
- **順序立てる：** 時間や手順、変化の過程を整理する
- **まとめる：** 考えを構造化し、自分の言葉で説明・振り返りを行う

一つのツールに当てはめるだけで終わらず、書き込んだ内容を比べたり、根拠を確かめたり、友達と説明し合ったりする活動につなげることを想定しています。

## ナビキャラについて

画面内のナビキャラは、ツールの使い方や考える視点を案内する補助役です。キャラクター画像は共通素材リポジトリのWebP画像を参照しています。

- 素材リポジトリ：[TT-sensei/navi-character-](https://github.com/TT-sensei/navi-character-)
- 画像の参照先：`assets/web/characters/`
- 使用するポーズやファイル名は、素材リポジトリのカタログ・利用案内を基準にしています。

## 技術構成・設計方針

- HTML / CSS / JavaScriptによる静的サイト
- サーバー、データベース、ビルド工程なし
- APIキー、外部API、生成AIサービスへの接続なし
- 外部ライブラリ、CDN、外部フォントに依存しない構成
- 入力データはブラウザの `localStorage` に保存
- PC・タブレット・スマートフォンで利用できるレスポンシブ設計
- 印刷時は操作用UIを省き、思考シートとして出力

## 入力データとプライバシー

入力内容は、利用している端末のブラウザ内に保存されます。THINK LABのサーバーへ送信する仕組みはありません。

ただし、次の場合は入力内容が引き継がれないことがあります。

- 別の端末やブラウザで開いた場合
- ブラウザの閲覧データ・サイトデータを消去した場合
- プライベートブラウズなど、保存データが保持されない環境で利用した場合

必要な記録は、印刷またはPDF保存を行ってください。端末を共有する場合は、個人情報や公開したくない内容を書き込まないようご注意ください。

## 改善の記録と引き継ぎメモ

2026-11-13に、ぷるん（Muse）が4段階で改善しました。引き継ぐときは、このメモと `AI-GUIDE.md` の設計ルールを先に読んでください。

### まず押さえること

- 構成は `index.html` の単一ファイル（CSS・JavaScript内蔵）。同梱は `references.html`、`README.md`、`AI-GUIDE.md`
- 保存データの形式は変えないこと：`localStorage` のキー `thinklab:<ツールID>`、中身は `{topic, blocks, labels}`。`labels` は第2弾で追加したもので、無いツールでは読み込み時に補完される。ふりがな設定は `thinklab:furigana`
- ツールのID・分類・データの並びは保存データと結びついているので変更しない
- 外部API・CDN・外部フォントは使わない。読み込む画像は navi-character- のものだけ

### 第1弾（公開と細部の修正）

- GitHub Pagesを有効化して公開（それまでは未設定で404だった）
- 座標軸チャートの右上・左上の表示位置が入れ替わっていた問題を、CSSの配置指定で修正（保存データの並びはそのまま）
- マトリックスを2×2の配置に、比較表を「視点｜A｜B」の横並びの表に
- 原因と結果に、流れの矢印を追加
- PMIシートの分類をREADMEに合わせて「分析する」に統一
- faviconを追加。子ども向け画面のフッターにあったGitHubリンクを削除

### 第2弾（レイアウトの見直し）

- ベン図を2円の重なり＋中央の共通枠に再設計。フィッシュボーンに背骨・骨・「結果」の頭、マインドマップ系に幹と枝の接続線を追加
- ベン図・比較表に比べるもの（A・B）の名前入力、マトリックスに縦・横の条件入力を追加し、見出し・欄・図に反映（`labels`）
- タブレット幅（1200px以下）では案内を下に回してシートを全幅に。入力欄の文字を14pxに拡大
- ふりがなON/OFFを追加（読みが固定した語だけの辞書方式。子どもの入力文には付けない）
- ホームのカードに「● 入力あり」表示。使い方のコツの開閉を往復化。削除ボタンのタップ範囲を拡大
- 印刷時にベン図の中央枠が隣の見出しに重なる問題を修正

### 第3弾（図と入力の分離）

- 要望「図の上に入力欄があると全体像が見えない。入力は脇に移して、打った文字が図に反映される形にしたい」を受けて、図形系25ツールで編集画面を「図で見る」パネル＋「入力する」リストに分離
- 入力は打鍵ごとに図へ即時反映。項目の追加・削除も図に連動
- 印刷は入力側を出さず、図だけを出力
- 対象外：比較表・マトリックス・PMI・KWL（表として読むもの）と、ダイヤモンドランキング（並びがきれいにできているため、現状維持の指定があったもの）

### 第4弾（図の上に文字をのせる）

- 第3弾の図は白いカードに円が隠れて「ベン図のよさがない・丸が見えない」との指摘を受け、学研・コラボノートの思考ツールの見せ方を参考に作り替え
- ベン図・フィッシュボーン・座標軸・ピラミッド・同心円・バタフライ・Yチャートの7ツールは、図（SVG）を全面に敷いて、文字を領域の上に直接のせる方式に。ベン図は半透明の2円＋名前ピル、座標軸は軸の端に軸名、同心円は輪の帯に文字、フィッシュボーンは頭に「結果＋テーマ」
- 残りの分離ツールも、図側のカードをなくし、線と構造の上に文字が見える形に統一

### 図の見せ方の原則（ユーザーの指定）

- 図そのものが大きく見えること。文字は図の上に直接のせる（「画像の上に文字を乗っける」イメージ）
- 入力欄や白いカードで、図の形を隠さない
- 参考：学研の道徳デジタルコンテンツのベン図（イチゴとバナナの例）、コラボノートの思考ツールテンプレート、日本文教出版のシンキングツール
